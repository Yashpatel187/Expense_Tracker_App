## 📌 Project Overview

**Aether Wallet** is a full-stack digital wallet application featuring a Flutter-based mobile frontend and a secure backend service. Designed for efficient wallet operations and transaction management.

---

## ✨ Features

- 💰 **Wallet Management** — Create, view and manage digital wallets
- 🔄 **Transaction Handling** — Send, receive and track transactions
- 🔐 **Secure Backend** — Authenticated API with data protection
- 📱 **Flutter UI** — Clean, responsive cross-platform mobile interface
- 📊 **Transaction History** — Full audit trail of all operations

---

## 🚀 How to Run

```bash
# Clone the repo
git clone https://github.com/apcyash1212/Aether-Wallet---App.git
cd Aether-Wallet---App

# Install Flutter dependencies
flutter pub get

# Run the app
flutter run
```
