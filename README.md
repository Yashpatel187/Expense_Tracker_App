# Personal Expense Tracker
A modern, user-friendly platform designed to replace complex spreadsheets with an intuitive dashboard for managing personal finances.

# Key Features
Expense & Income Logging: Easily record daily transactions with descriptions, amounts, and dates.
Smart Categorization: Group spending into categories like Food, Rent, and Transport.
Visual Analytics: Interactive pie charts and bar graphs to visualize spending trends over time.
Budget Management: Set monthly spending limits for specific categories and receive alerts.
Secure Authentication: User signup and login with JWT and password hashing.
Data Export: Download your financial history as CSV or PDF reports.

# Technology Stack
Frontend: Flutter / Tailwind CSS for a responsive UI.
Backend: Node.js ,Python &  Express for the REST API.
Database: MongoDB (NoSQL) or SQLite for transaction storage.
